# Focal VPN — sing-box для проектора

Установлено на P30 9 ноября 2026 года. Кнопка **VPN** в верхней строке focal-launcher (прежнее имя Rice) включает и выключает VPN. Долгое OK на кнопке открывает клиент для просмотра профиля и соединения. `VPN · …` означает переход; повторные нажатия в этот момент игнорируются. `VPN · вкл` берётся из состояния службы, а не из последнего нажатия.

При включении клиент скачивает `URL из локального local/vpn.json` по HTTPS. При недоступности загрузки используется последняя сохранённая конфигурация; при ошибке проверки новой конфигурации запуск отменяется. Файл и ключи хранятся в закрытом каталоге клиента. Они не включены в APK, исходники или отчёт. На первом запуске использовано обычное системное разрешение Android на VPN.

## Совместимость

Основой служит официальный SFA 1.14.4 для `armeabi-v7a`, API 24+, с неизменёнными нативными библиотеками. Для управления из Rice добавлены одна Activity, read-only ContentProvider, отдельный DEX и разрешение уровня `signature`. Оба приложения подписаны одним локальным ключом. Оболочка ADB и посторонние приложения не могут обращаться к этому интерфейсу. Это локально изменённая сборка **Focal VPN**, она не является официальной сборкой SagerNet и не связана с авторами исходного клиента.

Исходный конфиг адаптируется перед проверкой:

- DHCP DNS заменяется на системный `local` с тем же тегом: официальный Android libbox не содержит `with_dhcp`.
- В TUN добавляются исключения для локальных сетей, loopback и link-local. Из VPN исключены `com.android.shell` и Rice; ADB и управление проектором остаются доступны по Wi-Fi.
- Контроллер Clash разрешён только на loopback; если пароль отсутствует, создаётся случайный локальный пароль.

Выбор серверов и правила из конфигурации сохраняются. Обычные приложения проектора используют VPN по этим правилам. Root, изменение прошивки, reboot и постоянная блокировка сети для работы не нужны. Автоматическое обновление самого клиента отключено, чтобы оно не заменяло локальный интерфейс управления. Обновления upstream требуют повторной адаптации и проверки; обфусцированный Kotlin ABI закреплён под хеш исходного APK.

## Историческая проверка на проекторе

Включение, выключение и повторное включение с помощью OK на кнопке лаунчера. Отдельное временное приложение подтвердило Android VPN transport и HTTPS 204 при включённом VPN, отсутствие VPN transport и HTTPS 204 после выключения. ADB оставался доступен; маршрут к шлюзу `192.168.1.1` шёл по `wlan0`. Во время того теста HOME ещё был `com.chihihx.launcher/.ui.activity.MainActivity`; позднее владельцем выбран Rice, актуальное состояние — `../docs/CURRENT-STATE.md`. Перезагрузка и поведение после неё не проверялись.

Результаты: `../evidence/rice-vpn-verification.json`. Проверочное приложение после теста удалено.

## Выключение и откат

Обычно достаточно нажать кнопку VPN. Если клиент завис, с Mac можно остановить только его:

```sh
adb -s 192.0.2.74:5555 shell am force-stop io.nekohasekai.sfa
```

Android закроет VPN-интерфейс при завершении процесса. Для полного удаления только VPN-клиента:

```sh
adb -s 192.0.2.74:5555 uninstall io.nekohasekai.sfa
```

Удаление стирает скачанный профиль и разрешение VPN; Rice продолжает работать. Для возврата старого поведения следует собрать нужные исходники с большим versionCode и тем же оригинальным ключом. Удалять лаунчер или очищать данные ради downgrade/ошибки подписи нельзя. Штатная оболочка не удалялась и не отключалась.

## Сборка и исходники

`build.py` принимает только исходный SFA APK с SHA-256 `b1ae76164e1f518c0ae343ce30d8ee63fbb46a59f1e12295bf5bd20f1e1a5e1b`. Исходный APK: [релиз sing-box 1.14.4](https://github.com/SagerNet/sing-box/releases/tag/v1.14.4), файл `SFA-1.14.4-armeabi-v7a.apk`.

Из корня Git-репозитория:

```sh
make build
make vpn
```

Нужны JDK 21, Android SDK Platform 30 и Build Tools 35, исходный SFA APK и общий ключ подписи Rice. Параметры задаются в `local/build.mk`, HTTPS endpoint и имя профиля — в `local/vpn.json`; см. `../docs/DEVELOPMENT.md`. Builder генерирует приватный VpnBuildConfig только в игнорируемом work-каталоге. Ключ не включён в архив. Сборка не подключается к устройству. После сборки проверяются подписи APK и побайтное совпадение всех нативных библиотек с upstream.

`axml_bridge.py` редактирует манифест, сохраняя исходные индексы ресурсов; Android-атрибуты новых узлов сортируются по resource ID. `src/` содержит весь добавленный код. `qa/` содержит временный сетевой тест, который собирается и устанавливается отдельно.

В `upstream/` сохранены исходники sing-box v1.14.4 и Android-клиента на коммите `f87c2ebdb7e34754be751bb5e58926db2fed8f8c`, указанном в submodule `clients/android` этого релиза. Оригинальное уведомление — `UPSTREAM-LICENSE.txt`; полный GPL v3 — `COPYING`. Добавленный код предоставляется на условиях GPL-3.0-or-later. Локальный ключ подписи и закрытая конфигурация к исходникам не относятся.

Прежняя установленная сборка называлась Rice VPN. В focal-launcher она отображается как Focal VPN без изменения установленного APK и профиля. Будущие сборки используют название `Focal VPN` и файл `dist/focal-vpn-1.14.4.apk`; package ID, подпись и API остаются совместимыми.
