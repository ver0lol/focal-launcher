# focal-launcher для проектора

Минималистичный домашний экран для Android 11 в духе Linux rice: тёмный фон, моноширинные подписи, спокойный акцент и управление пультом. Версия 0.5.3 — отдельное приложение `dev.projector.rice` с надписью `_VeR0`. Главный экран и VPN работают без root. Веб-пульт использует уже имеющуюся заводскую службу для отправки нажатий; изменение прошивки не требуется.

## Возможности

- Часы, дата и статус сетевого подключения.
- Схематичная Солнечная система: Солнце, восемь планет, кольца Сатурна и пояс астероидов. Размер рассчитывается по доступной области с учётом наклона, чтобы все орбиты помещались целиком.
- Кнопка VPN с реальным состоянием sing-box; долгое OK открывает VPN-клиент. Интеграция описана в `../singbox-integration/README.md`.
- Веб-пульт по `http://<IP-проектора>:8080/`, подключение по коду, работа в фоне. Адрес и код доступны в настройках. Инструкция: `../docs/WEB-REMOTE.md`.
- Четыре места для избранных приложений.
- Общий список приложений с поддержкой обычных и Android TV точек запуска, без повторов одного пакета.
- Навигация стрелками и OK, явный порядок переходов фокуса.
- MENU или удержание OK открывает добавление и удаление из избранного.
- Избранное и цветовой акцент сохраняются в собственных настройках приложения.
- Четыре акцента: лаванда, шалфей, лёд, янтарь.
- Переходы к Wi-Fi, Bluetooth, системным настройкам и родному главному экрану P30.

Экран рассчитан на 1280×720 при плотности 160 dpi и масштабируется под другие размеры. Разрешения — чтение состояния сети, локальный HTTP-сервер, фоновая служба, запуск после загрузки и управление VPN-клиент с общим сертификатом подписи. Список приложений определяется локально. Сетевые ключи остаются в VPN-клиенте. Сетевой процесс веб-пульта работает под обычным UID; разрешённые нажатия отправляет готовый обработчик с UID 2000 без root, запускаемый через существующий заводской qw. Произвольные shell-команды из сети не принимаются.

В предпросмотрах показаны приложения виртуального Android. На проекторе появятся его реальные приложения. Экранов фокуса и трапеции внутри focal-launcher пока нет: для них предусмотрен переход к штатной оболочке.

## Сборка

Из корня Git-репозитория:

```sh
make build
```

Текущие локальные пути задаются в игнорируемом `local/build.mk`; подробности — в `../docs/DEVELOPMENT.md`.

Для отдельной распакованной копии укажите каталоги явно:

```sh
python3 launcher/build.py --bootstrap --sdk ./work/android-sdk --work ./work/build --output ./focal-launcher.apk --java-home /path/to/jdk-21
```

Сборка использует JDK 21, официальный Android SDK Platform 30 и Build Tools 35.0.0. `--bootstrap` скачивает закреплённые пакеты Google и проверяет их контрольные суммы. Gradle, внешние библиотеки, аккаунты и сетевые ключи не нужны. Сборка подписывается локальным ключом разработки; он хранится в каталоге сборки с правами 0600 и не включён в архив исходников. Сохраните этот ключ для совместимых обновлений APK.

## Проверка

`qa/verify_emulator.py` — исторический сценарий раннего интерфейса, пока не обновлённый под 0.5.3; это не действующий регрессионный тест. Он предназначен только для отдельного `emulator-5580` с hardware=ranchu и Android API 30. Перед любым действием он проверяет, что это виртуальное устройство. Скрипт отказывается работать с физическим проектором. Он проверяет запуск, обнаружение приложений, навигацию пультом, избранное после завершения процесса, долгое нажатие, переход в Wi-Fi, смену акцента и запуск приложения.

Подписи APK v2 и v3 проверяются при сборке. APK содержит только DEX и ресурсы, без привязанных к ARM64 нативных библиотек: подходит для ARM32 Android проектора. Проверки навигации выполнены на виртуальном Android 11. С согласия владельца APK также установлен и открыт на P30; отображение подтверждено снимком экрана. Физический пульт на P30 ещё предстоит проверить владельцу.

Инструкция пробной установки и возврата находится в `../docs/LAUNCHER-INSTALL.md`. По явному запросу владельца focal-launcher назначен домашним экраном по умолчанию; кнопка Home проверена. Штатная оболочка не отключена и доступна через настройки.

## Темы

В версии 0.4.0 основной стала палитра владельца: фон `#0B0B10`, панели `#16181D`, границы `#343B49`, текст `#C9CAD4`, второстепенный текст `#7B8496`, акцент `#AAA6C4`, выделение `#454157`. При первом открытии обновления прежний акцент заменяется лавандовым; избранное и настройки пульта сохраняются.

Настройки → Тема: «Лаванда · по умолчанию» или «OLED · чёрный фон». OLED использует фон `#000000` и панели `#0B0B10` с той же палитрой текста. Выбор сохраняется. Солнечная система сохраняет естественные цвета планет, орбиты используют акцент темы.

Внизу веб-пульта есть переключатель «тема: лаванда / OLED». Браузер хранит свой выбор отдельно от проектора. Для загрузки новых цветов на уже открытом пульте обновите страницу.

## Автозапуск после включения

Версия 0.4.1 после BOOT_COMPLETED открывает выбранный домашний экран focal-launcher однократно. На этом проекторе прошивка явно запускала штатную Activity от UID 0, хотя HOME уже был focal-launcher. Новый обработчик дожидается готовности shell-UID ввода и отправляет Home. Повторное событие в том же включении игнорируется; при другом выбранном HOME переход не выполняется. Ключ текущей загрузки хранится в закрытых настройках приложения.

Штатная оболочка и её компоненты сохраняются для настроек проекции. Автозапуск выполняется и при выключенном веб-пульте; в таком случае временная служба останавливается после перехода. При обычном перезапуске службы пульта или обновлении APK экран не перехватывается. Проверены адресный сигнал загрузки и игнорирование его повтора. После настоящей перезагрузки владелец сообщил о появлении штатного лаунчера. Устойчивый автозапуск остаётся открытой задачей. Отчёт: `../evidence/boot-home-0.4.1.json`.

## Ввод текста с веб-пульта

Версия 0.5.0 добавляет кнопку «клавиатура», фокус поля телефона, отправку строки, удаление символа и Enter. Поддерживается печатный ASCII до 256 символов. Кириллица отклоняется без частичного ввода. У TizenTube есть ограничения регистра и знаков с Shift; подробности и проверки находятся в `../docs/WEB-REMOTE.md`. Текст не записывается в файлы или журналы и не интерполируется в shell. Очередь текста и кнопок общая, повторная отправка при сетевой ошибке не выполняется.

## YouTube

Начиная с версии 0.5.2 приложение `io.gh.reisxd.tizentube.cobalt` отображается как «YouTube» в списке и избранном. Старый избранный ярлык `com.google.android.youtube.tv` однократно заменяется ярлыком TizenTube с сохранением позиции и без дублей. Существующий ярлык TizenTube сохраняется. APK и данные TizenTube не меняются, поэтому вход в аккаунт и обновления разработчика сохраняют совместимость. Обычный YouTube и SmartTube удалены по запросу владельца, установщики сохранены отдельно. Отчёт: `../evidence/youtube-cleanup-and-rename.json`.
