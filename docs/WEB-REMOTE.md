# Веб-пульт _VeR0

Адрес: **http://<IP-проектора>:8080/**; фактический IP показан в настройках лаунчера. Телефон и проектор должны быть в одной Wi-Fi сети. Страница работает на самом проекторе; Mac после установки не нужен. Если роутер изменит IP проектора, новый адрес показывается в настройках лаунчера.

На новом телефоне введите шестизначный код из **настройки _VeR0 → Веб-пульт**. Браузер запоминает подключение на семь дней. «Новый код» на проекторе отключает все ранее подключённые браузеры; «Выключить» останавливает веб-пульт. Кнопка «отключить телефон» на странице отключает только текущий браузер.

Есть стрелки с удержанием, OK, назад, главная, меню, воспроизведение/пауза, отключение звука и громкость. «Главная» нажимает системную Home; сейчас домашним экраном назначен _VeR0. На компьютере работают стрелки, Enter, Esc, Home, пробел и +/−; если кнопка страницы имеет фокус клавиатуры, Enter нажимает её. Кнопки питания и перезагрузки не добавлены.

Веб-пульт работает и при открытых других приложениях. Постоянная обычная Android-служба с уведомлением удерживает HTTP-сервер в фоне. Предусмотрен запуск при открытии лаунчера, обновлении APK и BOOT_COMPLETED. После включения пользователем в этом сеансе подтверждён самостоятельный запуск веб-пульта. Автопереход на focal-launcher в 0.4.1 проверен отдельно адресным сигналом загрузки; реальный цикл питания после обновления агент не выполнял. Если прошивка очищает `/data/local/tmp`, установщик ниже повторно подготовит вспомогательный файл.

## Установка и возврат

Из корня Git-репозитория:

```sh
make build
make install
```

Установщик сверяет серийный номер, модель, ABI, платформу и хеши штатных бинарников, проверяет уже работающий заводской qw и сокет, затем сохраняет обычную копию штатного sh в `/data/local/tmp/ver0-web-remote-20261109/.agingdragonbox`. Каталог принадлежит shell, права 0755; файл 0555. Он не содержит изменений и совпадает по SHA-256 с `/system/bin/sh`. Прежний закрытый каталог исследования root не меняется.

Для отключения достаточно **настройки → Веб-пульт → Выключить**. Это не затрагивает VPN. После force-stop всего focal-launcher Android остановит также веб-сервер; повторное открытие лаунчера запускает его, если веб-пульт разрешён в настройках.

## Устройство реализации

HTTP-сервер слушает порт 8080 под обычным UID приложения `dev.projector.rice`. Подключения принимаются только с локальной Wi-Fi/Ethernet подсети или loopback. Проверяются Host и Origin; команды требуют случайного токена подключённого браузера. Токены хранятся на проекторе только в виде хешей; PIN и токены не включены в исходники или APK. Число попыток ввода кода, соединений, очередь команд и размер запросов ограничены.

Сервер не предоставляет shell, запуск произвольной Activity или загрузку файлов. С версии 0.5.0 есть ограниченный ввод текста в активное поле: до 256 печатных ASCII-символов, с той же проверкой подключения и Origin. Текст не сохраняется и не попадает в журналы; он передаётся в Base64 по частному каналу и преобразуется в события клавиатуры без shell-интерполяции. Начиная с 0.3.2, существующий factory qw один раз запускает обработчик ввода с UID/GID 2000 и нулевым CapEff, после чего завершает запрос. Между нажатиями не остаётся root-процесса запроса: штатный daemon сохраняет свой PID. HTTP-сервис работает под UID приложения, обработчик ввода — под обычным shell UID; ни один из них не работает как root.

Обработчик загружается из установленного APK через app_process и соединяется с приложением по одноразовому локальному Unix-каналу со случайным именем. Обе стороны проверяют UID/PID собеседника. Канал не доступен по IP; обработчик не слушает сокетов и принимает четырнадцать разрешённых кнопок, ограниченный текст и служебный ping. Он отправляет пары key-down/key-up через InputManager без повторного запуска Android на каждое нажатие. При закрытии канала или исчезновении приложения обработчик завершается. Вспомогательный файл и штатные бинарники проверяются до запуска; при несовпадении пульт не отправляет нажатия. Прошивка, USB, загрузчик, правила сети и eMMC-разделы не меняются.

## Клавиатура телефона

Обновите страницу пульта после установки 0.5.0. Выберите поиск или другое поле на проекторе, нажмите «клавиатура» на веб-пульте, наберите текст и нажмите «Ввести». Кнопки ⌫ и ↵ удаляют символ и отправляют Enter на проектор. Enter на клавиатуре телефона отправляет набранную строку; содержимое очищается только после подтверждения. При ошибке черновик остаётся, автоматической повторной отправки нет.

Поддерживается печатный ASCII до 256 символов. Кириллица отклоняется целиком перед отправкой: виртуальная аппаратная раскладка Android её не содержит. В TizenTube подтверждён буквенно-цифровой ввод; интерфейс YouTube приводит буквы к нижнему регистру, а часть знаков с Shift интерпретирует иначе. Для этих знаков можно использовать клавиатуру на экране YouTube. Общесистемная клавиатура Android не заменяется. В мобильном браузере клавиатуру открывает нажатие пользователя, автоматическое открытие без касания не выполняется.

Проверки: `evidence/web-keyboard-http-0.5.0.json` и `evidence/web-keyboard-0.5.0.json`. Прямую проверку системной клавиатуры физического телефона выполняет владелец; на Mac подтверждены фокус поля при нажатии и передача текста.

Исходники HTTP-интерфейса находятся в `launcher/assets/remote/`, сервер и обработчик кнопок — в `launcher/src/dev/projector/rice/Remote*.java`. На странице нет внешних шрифтов, CDN, аналитики или внешних ресурсов. Проект предназначен для управления в локальной сети.

## Проверка

На физическом P30 подтверждены работа страницы, подключение по коду, нажатия из браузера, работа сервиса в фоне и совместимость с включённым VPN. Владелец также управлял проектором из веба во время проверки. HTTP-процесс имеет обычный UID; исходный qw daemon сохранил PID 2457. Проверены запрет команд без подключения, блокировка другого Host/Origin, неизвестных кнопок и дополнительных параметров, а также отзыв отдельного токена. Результаты: `evidence/web-remote-verification.json`.

Повторить проверку без отправки нажатий:

```sh
python3 launcher/qa/check_remote_http.py --url "http://IP-ПРОЕКТОРА:8080" --report work/web-remote/http-checks.json
```

Код вводится скрыто в терминале. Скрипт подключает временную тестовую сессию и затем отключает её. Текущие пользовательские сессии он не отзывает.

## Задержка в версии 0.3.2

Раньше каждое нажатие заново запускало Android input: диагностические запуски заняли 1223–1373 мс. Теперь готовый обработчик отправляет события напрямую. Шесть последовательных команд по HTTP с Mac в той же сети получили подтверждение за 33–47 мс, медиана 36,9 мс. Это время до подтверждения постановки события в Android, а не измерение момента перерисовки экрана. Первый запуск обработчика занимает около 1,5 с один раз при запуске службы.

Кнопки отправляются при касании, а не после отпускания. Быстрые отдельные клики сохраняются в ограниченной очереди, удержание не создаёт очередь повторов; устаревшие команды после сетевой задержки отбрасываются. После обновления APK нужно перезагрузить открытую страницу, чтобы получить новый клиент.

Офлайн-проверки клиента находятся в `launcher/qa/check_remote_client.cjs`; они проверяют момент отправки, порядок быстрых кликов, клавиатуру и отбрасывание устаревших команд, не управляя проектором. Отчёт: `evidence/web-remote-latency-0.3.2.json`.

## Темы интерфейса

По умолчанию используется лавандовая палитра владельца. Кнопка темы внизу страницы включает OLED с фоном `#000000`; повторное нажатие возвращает основную тему. Выбор хранится в браузере отдельно от подключения и от темы проектора. На проекторе тема выбирается через настройки _VeR0 → Тема. После установки 0.4.0 перезагрузите уже открытую страницу пульта.

В версии 0.5.1 выделение надписей пульта и системное меню долгого касания в Safari отключены через `user-select` и `-webkit-touch-callout`. Для полей PIN и текста сохранены обычное выделение и вставка. После обновления APK обновите открытую страницу.

## Примечание при передаче

Пути `evidence/` выше — ссылки на результаты исходного исследования; личные отчёты не входят в архив. После настоящей перезагрузки владелец сообщил о штатном экране вместо focal-launcher; надёжный автозапуск остаётся открытой задачей. Это не влияет на публикацию исходников.
