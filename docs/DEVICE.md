# Проектор, для которого сделан focal-launcher

Предположительно P30, OEM **P30_H713_V1.1_CHIHI_emcp**. Торговое название и маркировка платы физически не сверены. Проверенные свойства получены из Android и исходных boot-образов 9–10 ноября 2026 года.

| Параметр | Проверенное значение |
| --- | --- |
| Платформа | Allwinner H713M, `sun50iw12p1`, `ares`, 4 логических ядра |
| Android / ABI | 11 / API 30, `armeabi-v7a` (ARM32) |
| Ядро | Linux 5.4.99 |
| Видимая RAM | `MemTotal: 1474000 kB`, около 1,41 ГиБ |
| eMMC | 7 818 182 656 байт, около 7,28 ГиБ |
| Экран Android | 1280 × 720, 160 dpi; физическая матрица отдельно не проверена |
| Прошивка | `H713M-android11-v1.0`, `202410161629`, `OB.283` |
| Связь | ADB по локальной сети; личный адрес и serial отсутствуют в Git |
| Factory-доступ | SELinux Permissive; существующая служба `qw` позволила root без прошивки |
| Загрузка | Рабочий слот `_a`; сохранённые разделы `_b` нулевые |

Generic Google fingerprint и `mainline` не являются надёжной моделью устройства. Лаунчер и веб-ввод проверялись именно на этой прошивке; это не обещание совместимости с любым P30 или Android TV.

Лаунчер — обычный Android APK. Веб-пульт использует узкий обработчик ввода UID 2000, запускаемый через уже работающую заводскую службу. Установка Magisk ему не нужна.

Независимое восстановление после ошибки прошивки не подтверждено. Исследование root, AVB, boot-образов и условная процедура восстановления находятся в отдельном репозитории **projector-root**. Исходные образы и личные настройки в оба публичных репозитория не включены.
