## Темы и интерфейс

Лаванда: фон `#0B0B10`, панели `#16181D`, границы `#343B49`, основной текст `#C9CAD4`, второстепенный `#7B8496`, акцент `#AAA6C4`, выделение `#454157`. OLED: фон `#000000`, панели `#0B0B10`, остальные цвета те же. Тема веб-пульта хранится в браузере отдельно от темы focal-launcher.

Главный экран содержит часы, дату, солнечную систему целиком, четыре избранных места, список приложений, VPN и настройки. В штатные настройки ведёт отдельная кнопка; программная геометрия/трапеция не реализуется заново.

## Веб-пульт

Четырнадцать разрешённых кнопок, удержание стрелок/громкости/удаления, ограниченная очередь, отбрасывание устаревших повторов. Клавиатура открывается по нажатию на телефоне и отправляет строку в активное поле проектора. Есть удаление символа и Enter. Выделение надписей отключено, поля ввода сохраняют выделение/вставку.

Текст: 1–256 печатных ASCII-символов. Кириллица пока отклоняется целиком. У TizenTube некоторые знаки с Shift интерпретируются иначе, буквы приводятся к нижнему регистру; буквенно-цифровой ввод подтверждён на устройстве. Неподтверждённая отправка не повторяется автоматически. Не заявляйте поддержку Unicode до проверки в реальном поле Cobalt: clipboard paste там добавлял букву `v`, а ACTION_MULTIPLE не принимался Android InputDispatcher.

HTTP-ответ кнопки после исправления задержки был около 37 мс в локальной сети; это измерение конкретного сеанса, а не гарантия. Старый запуск новой Android VM на каждую кнопку удалён. Обработчик UID 2000 живёт с процессом focal-launcher, root-процесс запроса не остаётся.

## Автозапуск и root

На BOOT_COMPLETED focal-launcher один раз вызывает выбранный HOME после готовности обработчика ввода. Повторы в том же включении не перехватывают экран. При обновлении APK запускается веб-служба без принудительного открытия Home. **Известная проблема:** адресная симуляция boot callback проверена, но после реальной перезагрузки владелец сообщил, что открывается штатный лаунчер. Устойчивый автозапуск пока не исправлен; выбранный HOME сам по себе не исключает vendor-автозапуск.

Factory root доступен через уже работающий qw; Magisk для оболочки не нужен и не установлен. Патч boot подготовлен только как исследовательский кандидат. Восстановление после прошивки не подтверждено; все запреты AGENTS.md действуют.

## Куда двигаться дальше

- Unicode-ввод с телефона: отдельное исследование, без ослабления сетевого API и shell-интерполяции.
- Яркость: в TvSettings найдены BrightnessFragment/BacklightFragment и управление `/sys/class/projection/duty_of_max_brightness`. Значения зависят от модели; физическое изменение света не проверялось. Android brightness около 40% и `/sys/class/backlight/tv` 100/100 не совпадают. Не превращать эти числа в неподтверждённый регулятор LED и не менять вентилятор.
- Исследовать, какой vendor-компонент открывает штатный экран после загрузки, и исправить автозапуск без бесконечного перехвата фокуса. Проверка питания только владельцем; агент сам не перезагружает.
- Воспроизводимые проверки новых функций и документация миграций, без стирания существующих предпочтений.

Приватные `project.json` и `evidence/` в исходной рабочей копии содержат подробную историю и измерения. В архив они не входят; этот документ — проверенное краткое описание для нового агента.

## Название focal-launcher

С версии 0.5.3 пользовательское имя приложения и каталога репозитория — `focal-launcher`. Прежнее название — Rice. В шапке остаётся заданная владельцем подпись `_VeR0`. Пакет `dev.projector.rice`, файлы настроек, ключ подписи и RPC идентификаторы сохранены для совместимого обновления. VPN в списке приложений подписан «Focal VPN»; существующий APK клиента, профиль и соединение не заменялись. Новые сборки VPN companion получают имя Focal VPN.
