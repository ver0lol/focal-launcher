# Установка и обновление focal-launcher

На проекторе владельца уже установлен focal-launcher 0.5.3. Для публикации на GitHub переустановка не нужна.

## Arch Linux x86_64

Один раз распакуйте отдельный PRIVATE update kit в корень репозитория. Он содержит оригинальный ключ и проверенную привязку устройства в игнорируемом local/. Затем для любых разрешённых изменений приложения:

```sh
./focal update
```

[Полная инструкция](ARCH-LINUX.md) объясняет первоначальную настройку, изменение IP и ежедневную разработку. Команда готовит инструменты, проверяет исходники и сертификат, собирает APK и обновляет устройство обычным adb install -r. Тему, избранное, настройки и подключённые телефоны сохраняет Android.

## Сборка и установка по отдельности

```sh
./focal build
make install
```

Для своих путей используются параметры focal или local/build.mk для Make. Установщик проверяет хеш и сертификат APK до обращения к ADB, затем идентичность P30, штатные sh/qw и уже работающий factory daemon. Вспомогательный shell — обычный файл, не изменение прошивки.

Нет reboot, raw-записи, удаления APK, очистки данных, запуска root daemon или смены HOME. Если сертификат не подходит, установка останавливается: нельзя удалять старое приложение, чтобы обойти проверку. Нужен оригинальный ключ. Тестовая подпись не подходит для обновления установленной пары launcher/VPN.

## Домашний экран и штатные настройки

Выбор focal-launcher домашним экраном — отдельная настройка Android по просьбе владельца. Установщик её не меняет. Штатная оболочка сохранена и доступна через настройки лаунчера; не нужно удалять её для использования focal-launcher.

После реальной перезагрузки владелец сообщил о появлении штатного экрана. Исправление vendor-автозапуска остаётся открытой задачей. Обновление сборочных инструментов не означает её решения; самостоятельно перезагружать проектор для проверки нельзя.

## После изменения

Для выпуска повысить versionCode и versionName в launcher/AndroidManifest.xml, обновить CURRENT-STATE.md и проверить затронутую функцию. Если менялись assets веб-пульта, обновить страницу на телефоне. Простое возвращение старого кода выполняется новой сборкой с большим versionCode и тем же ключом, без удаления приложения.
